# NetShield Auditor

**NetShield Auditor** is an open-source command-line tool built for network and security engineers to automate the tedious review of firewall rules and access control policies using **Gemma 4**.

## Features
- **Automated Rule Analysis:** Instantly flags high-risk policies like `any-any` rules and open ports.
- **Actionable Remediation:** Generates structured Markdown reports with hardening recommendations.
- **Lightweight & Open-Source:** Powered by the Gemini API running Gemma 4.
